# Customer-Churn-Analysis  

- **Problem Statement**:  
  Customer churn prediction refers to identifying customers who are likely to stop using a product or service in the near future. It is a valuable predictive analytics technique used by businesses to forecast customer behavior and take proactive measures to retain customers.  

- **Objective**:  
  The objective of this project is to predict whether a customer is about to churn or not.  

- **Dataset**:  
  [Kaggle Telco Customer Churn Dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
